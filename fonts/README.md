# Polices locales

Sous-ensemble latin de deux polices japonaises de Google Fonts (licence SIL Open Font License 1.1) :

- M PLUS Rounded 1c (400, 700, 800) — thème « Night sky »
- Dela Gothic One (400) — thème « Shōwa poster »

Elles sont auto-hébergées avec `next/font/local` : via `next/font/google`, le build télécharge
les ~500 fichiers des glyphes japonais, alors que seuls les caractères latins sont utilisés
(les caractères japonais du logotype passent par la police système).
